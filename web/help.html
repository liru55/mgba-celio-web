使い方

ROMを選んで遊び、セーブをこのブラウザやファイルに残せます。

はじめるセーブ操作画面・写真チート通信交換困ったとき

はじめる

  1. エミュの「ROMを選ぶ」、または画面下の「ROM」を押します。
  2. 端末に保存したGBA / GB / GBCのROMを選びます。ZIPは先に解凍してください。最大64MBです。
  3. 画面ボタン、キーボード、接続したコントローラーで操作します。

iPhone / iPadはSafariで開き、共有メニュー →「ホーム画面に追加」で起動アイコンを作れます。初回の読み込みは通信が必要です。その後はキャッシュが残っていればオフラインでも起動できます。

セーブを残す・続きから遊ぶ

まずゲーム内で通常のセーブをしてください。ブラウザ保存はそのセーブデータを残す機能です。画面の途中から戻れる「どこでもセーブ」ではありません。

自動保存は初期状態でオンです。ゲーム実行中は約10秒ごとにこの端末のブラウザ内へ保存します。「設定」→「セーブ」には「今すぐブラウザに保存」と保存時刻の表示があります。

  1. 次回、同じROMを端末から選び直します。
  2. 保存済みのデータがあれば自動で読み込みます。
  3. ゲームの「つづきから」などで再開します。

画面上の「クイック保存」はゲームの途中の状態をこのブラウザに保存し、「ロード」でその時点へ戻ります。ROMごとに1つで、再保存すると上書きします。同じROMを選び直してもロードできます。通常のゲーム内セーブとは別の機能です。ロードするとその後の進行とセーブRAMも保存時点に戻ります。大切な通常セーブは先にファイルへ書き出してください。

ROMの中身で識別するため、名前を変えても同じセーブを復元できます。バージョンが違うROMは別の保存として扱います。

「ファイル」→「セーブ」→「セーブを書出」でファイルにも残せます。別のセーブや別バージョンへ移す場合は「設定」→「セーブ」→「別のセーブを選んで変更」を使ってください。選んだセーブは対応するROMで使ってください。

ブラウザのデータ削除、容量制限、プライベートブラウズなどで保存が失われることがあります。大切なセーブはファイルにも書き出してください。ブラウザ保存を削除すると、自動保存はオフになります。

画面上の「？」、または「設定」→「アプリ情報」からこの説明を開けます。キャッシュ削除とリセットは「設定」→「一般」にあります。

コントローラー・画面ボタン

コントローラーは端末のBluetooth設定などで接続し、ページを開いたあとパッドのボタンを一度押します。接続状態は画面上と「設定」→「操作」に出ます。

標準は下のボタン＝A、右のボタン＝B。方向キー・左スティック、L/R、SELECT/STARTに対応します。「操作」でA/Bを交換したり、実際に押したボタン番号を見ながら割り当てを変更できます。接続した機器をブラウザが認識する必要があります。

標準配置では縦向きはゲーム画面の下、横向きは左右に画面ボタンを配置します。PCでは初期状態で非表示です。「設定」→「操作」の「画面ボタンを表示」で切り替えられます。画面ボタンは「設定」→「操作」で重ね表示、大きさ、透明度を変更できます。「ボタンの位置を調整」ではボタン群をドラッグし、「調整を完了」で設定へ戻ります。縦・横の配置は別々に保存されます。

「設定」→「操作」の「十字キーをつなげてスライド操作する」は初期状態でオンです。指を離さず方向を変えられ、斜めも入力できます。中央はニュートラル、外へ大きく離すと入力が解除されます。オフにすると独立した4つのボタンへ戻せます。どちらでも長押しによる文字選択を防ぎます。

キーボード：方向キー、Z＝A、X＝B、A＝L、S＝R、Enter＝START、Shift＝SELECT。Spaceで一時停止、Fで画面拡大を切り替えます。

全画面・横向き・スクリーンショット

倍速・クイック保存・ロードの位置も変えられます。「設定」→「操作」→「ボタンの位置を調整」で、倍速・クイック保存・ロードの各ボタンを別々にドラッグし、「調整を完了」を押してください。全画面では右上の「設定」から同じ調整画面を開けます。縦向き・横向きで別々に保存します。「配置を初期化」で元の位置に戻せます。

「設定」→「表示」の「ゲーム画面の倍率」で50〜200%に変更できます。100%が画面に合わせたサイズです。拡大すると端が隠れる場合があります。「画面に合わせる」で戻せます。操作ボタンの大きさは別に調整できます。

「全画面」で拡大します。左上の薄い「通常画面に戻る」で戻せます。横向きにすると、画面の高さに合わせて操作ボタンを左右へ配置します。

「設定」→「表示」→「ボタンとメニューを隠す」で撮影用の表示にします。画面を一度タップするとボタンが戻ります。「ゲーム画面を画像で保存」なら、操作ボタンを含まないPNG画像を保存できます。

「設定」→「表示」→「シェーダー」でスキャンライン・液晶風・CRT風・xBRZ Freescale Multipassを選べます。xBRZはドットの輪郭をなめらかに拡大する2段階の処理です。xBRZ以外は効果の強さも調整できます。対応ブラウザではGPUで処理し、使えない場合は通常表示へ戻ります。PNG保存は効果を含まない元の画面です。

画面上の「倍速」で通常と倍速を切り替えられます。最初は2倍、以後は表示設定で選んだ倍速を使います。「設定」→「操作」の「倍速・クイック保存／ロードを画面に表示」でまとめて非表示にもできます。

「設定」→「表示」の「ゲームの速度」で1〜4倍を選べます。倍速中も音が出ます。ゲームに合わせて音も速くなり、高さが上がります。処理が重い端末では設定どおりの速度に届かない場合があります。

一時停止中はゲーム画面に「一時停止中・タップして再開」が出ます。この表示、またはゲーム画面の空いている場所をタップすると再開します。設定を開いている間は再開しません。

ツールバーの「音量」で音量とミュートをすぐ変更できます。「設定」→「音声」からも調整できます。通常は設定を開くとゲームを止め、閉じると開く前の状態へ戻ります。通信中は設定を開いてもゲームが進みます。

チートコード

  1. ROMを開きます。先にセーブのバックアップをおすすめします。
  2. 「設定」→「チート」を開きます。
  3. 名前とコードを入力します。複数行のコードは1行ずつ貼り付けます。
  4. 形式を選び、「コードを追加して有効にする」を押します。

追加後はチェックでオン／オフ、削除ボタンで解除できます。形式エラーは行番号で案内します。コードは今回の起動中だけ保持し、別のROMを開くと解除します。

ROMとバージョンに合うコードを使ってください。読み込みに成功しても、目的の効果が出るとは限りません。無効化しても変更済みのデータは元に戻りません。

機内モード・キャッシュ

  1. 通信できる状態で「設定」→「一般」を開きます。
  2. 「オフライン用に保存・更新」を押し、「準備完了」を確認します。
  3. ROMも端末の「ファイル」にダウンロードしておきます。クラウド上だけのファイルは機内モードで開けません。
  4. ホーム画面に追加しておくと、通信なしでも開きやすくなります。

アプリのキャッシュには有効期限を設けず保持します。ただし端末の容量不足やブラウザのデータ削除で消える場合があります。機内モードにする前に一度起動を確かめてください。「アプリのキャッシュを削除」はアプリの起動用ファイルだけを削除し、セーブ・設定を残します。削除後はオンラインで準備し直してください。

Celioの通信交換

ツールバーの「通信」から専用パネルを開き、「この端末で2台」または「オンライン」を選びます。部屋番号と待機・接続・通信中・終了の状態を上部に表示します。元のCelio版の通信処理を使うためROMの改造は不要です。GBA用のケーブル交換受付を選んでください。無線アダプター・GB/GBC通信は対象外です。

この端末で2台をつなぐ

  1. 自分のROMとセーブを開きます。
  2. 「2人目のセーブを選ぶ」で同じROM用の別のセーブを選びます。新しく始める場合は「最初から」をオンにします。
  3. 「端末内で通信を始める」を押し、1P／2Pを切り替えて両方をゲーム内のケーブル交換受付へ進めます。
  4. 交換後は両方のゲーム内でセーブし、「通信を保存して終了」を押します。2人目のセーブは別枠に保存します。

部屋番号でオンライン接続

  1. 2人とも同じゲーム・バージョンを開きます。
  2. 1人が「部屋を作る」を押し、表示された4桁の番号を相手に伝えます。
  3. もう1人が番号を入力して「番号で入る」を押します。
  4. 両方をゲーム内のケーブル交換受付へ進めます。交換後はゲーム内でセーブします。

元リポジトリのWindows版Celio内蔵通信と同じ部屋方式です。オンラインではCelio中継サーバーが必要です。ROMやセーブファイル全体は送らず、ゲームの通信ケーブルのデータだけを送ります。部屋番号は秘密の合言葉による認証ではありません。「自分のCelioサーバーを使う」から独自サーバーも指定できます。端末内の2台接続には外部通信がありません。

開始前のセーブはこの端末内にバックアップします。切断や画面を閉じた場合は通信前の状態へ戻します。通信中は倍速・一時停止・リセット・チート・クイック保存／ロードを停止します。設定を開いてもゲームが進みます。

困ったとき

チートなど、新しい項目が見当たらない

古い画面が開いたままの可能性があります。まずゲームをセーブし、ブラウザ保存またはファイル書き出しを済ませてから、ページを再読み込みしてください。ホーム画面から使っている場合も、閉じて開き直してください。

音が出ない

「ROM」や画面の操作ボタンを一度押してください。ブラウザは操作するまで音を出さないことがあります。ツールバーの「音量」、または「設定」→「音声」のミュートと音量、端末の音量も確認してください。

ROMが選べない・起動しない

端末の「ファイル」に保存して選びます。ZIPなら解凍して、ROM本体を選んでください。ゲームのROMは同梱していません。セーブファイルをROMとして選ばないようにしてください。

ブラウザ保存から戻れない

保存したときと同じROM内容、同じブラウザ・端末で開いてください。自動保存をオフにしていた場合は、手動で保存したデータだけが復元対象です。ファイルのバックアップがある場合はセーブの読み込みで復元できます。

全画面の戻るボタンが見えない

スクショ表示なら、ゲーム画面を一度タップして表示を戻します。通常は左上に薄い戻るボタンがあります。キーボードがあればFでも切り替えられます。

プライバシーと運営

ROMの読み込み・ゲームの実行はこの端末内で行い、ROMをサーバーや相手へ送信しません。ROM本体はブラウザ内に保存しません。セーブと操作設定はこのブラウザに保存できます。オンライン通信では、交換に必要な通信ケーブルのデータをCelio中継サーバー経由で相手へ送ります。

任天堂（Nintendo）とは関係のない非公式プロジェクトです。任天堂の承認・提供・運営によるサービスではありません。
