iPhone / iPadで使う

  1. 「ROM」で端末内のファイルを選ぶ
  2. 続きから遊ぶ場合は「セーブ」でファイルを読み込む
  3. ゲーム内でセーブし、必要に応じて「セーブを書出」でバックアップする

Safariの共有メニュー →「ホーム画面に追加」で起動アイコンを作れます。

キーボード

方向キー / Z：A / X：B / A：L / S：R / Enter：START / Shift：SELECT

Ctrl・⌘ + O：ROM / S：セーブ書出 / R：リセット / Shift + O：セーブ読込 / Space：停止 / F：画面を広げる
