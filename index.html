キャッシュ削除でもセーブ・設定は残ります。削除後は通信できる場所で保存し直してください。ROMは端末の「ファイル」にダウンロードしておきます。

iPhone / iPadで使う

  1. 「ROM」で端末内のファイルを選ぶ
  2. 続きから遊ぶ場合は「セーブ」でファイルを読み込む
  3. ゲーム内でセーブし、必要に応じて「セーブを書出」でバックアップする

Safariの共有メニュー →「ホーム画面に追加」で起動アイコンを作れます。

キーボード

方向キー / Z：A / X：B / A：L / S：R / Enter：START / Shift：SELECT

Ctrl・⌘ + O：ROM / S：セーブ書出 / R：リセット / Shift + O：セーブ読込 / Space：停止 / F：画面を広げる

プライバシーと運営

ROM・セーブの読み込みとゲームの実行はクライアント（この端末）内で行います。選んだROM・セーブはサーバーへアップロード・送信しません。セーブのブラウザ保存もこの端末内だけです。初回読み込み後はオフラインでも使えます。
